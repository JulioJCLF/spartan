## 🇺🇸 English Version

Spartan is a next-generation institutional website and interactive customer portal designed from the ground up to prioritize performance, SEO indexing, and usability. It serves as the primary hub for clients to browse offerings, book appointments, track active services, and download invoices or reports.

### ✨ Key Features
- **Client Dashboard**: A secure portal for clients to check service progress, view order history, and manage contact settings.
- **Service Showcasing**: Beautiful, responsive pages to display service packages and interactive quote calculators.
- **Ultra-High Performance**: Optimized static delivery achieving 100/100 scores in Google Lighthouse audits.
- **Built-in SEO & Accessibility**: Semantic HTML5 structure and JSON-LD structured data for search engine indexing.
- **Bilingual & Responsive**: Immediate translation toggling between English and Portuguese with fluid design adaptation for all screen sizes.

### 🛠️ Technologies
- **Frontend**: HTML5, Modern CSS (Custom Properties, CSS Grid, Flexbox), Vanilla JS.
- **Design & Layout**: Modern dark mode with tech accents, micro-animations, and fluid transitions.
- **SEO Optimization**: Open Graph tags, descriptive metadata, and mobile-first responsive layout.

### 🚀 Getting Started

#### Setup
1. Clone or copy the folder:
   ```bash
   cd Spartan
   ```
2. Simply open `index.html` in any web browser, or serve it using a lightweight local server:
   ```bash
   npx http-server -p 8080
   ```
3. Navigate to `http://localhost:8080` in your browser.

## 🇧🇷 Versão em Português

O Spartan é um website institucional e portal interativo para clientes, desenvolvido para priorizar velocidade de carregamento, indexação de SEO e facilidade de uso. Funciona como canal direto de comunicação para que clientes vejam serviços, solicitem orçamentos, acompanhem ordens ativas e acessem relatórios e notas fiscais.

### ✨ Funcionalidades
- **Portal do Cliente**: Área logada para acompanhar o status de ordens de serviço, histórico de projetos e gerenciar contatos.
- **Exibição de Serviços**: Páginas elegantes com calculadoras de orçamento interativas.
- **Performance Ultra Rápida**: Construído de forma enxuta, atingindo nota máxima (100/100) nas auditorias do Google Lighthouse.
- **SEO & Acessibilidade**: Estrutura HTML5 semântica e suporte a dados estruturados para melhor rankeamento no Google.
- **Bilinguismo e Responsividade**: Mudança instantânea de idioma (PT/EN) e layout adaptável para celulares, tablets e desktops.

### 🛠️ Tecnologias
- **Frontend**: HTML5, CSS Moderno (CSS Grid, Flexbox, Custom Properties), Vanilla JS.
- **Estilo e Design**: Tema escuro (dark mode), micro-animações interativas e transições suaves.
- **SEO**: Meta tags Open Graph, títulos descritivos e layout mobile-first.

### 🚀 Como Executar

#### Inicialização
1. Acesse o diretório do projeto:
   ```bash
   cd Spartan
   ```
2. Abra o arquivo `index.html` diretamente em seu navegador, ou utilize um servidor estático local:
   ```bash
   npx http-server -p 8080
   ```
3. Acesse `http://localhost:8080` no seu navegador.
