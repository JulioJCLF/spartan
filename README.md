## 🇺🇸 English Version

Spartan is a clean, high-performance landing page and institutional website featuring a seasonal waitlist system. Built to capture high-intent leads during specific release windows, it automates lead injection directly into spreadsheet databases for remarketing and sales.

### ✨ Key Features
- **Seasonal Waitlist**: Interactive registration form designed to capture leads, activating dynamically during campaign windows.
- **Spreadsheet Automation**: Instantly pushes captured user data (name, email, interests) to a linked spreadsheet database (via Google Sheets API, Webhooks, or Zapier).
- **Lead Generation Funnel**: Highly optimized layout with clean copy, trust badges, and structured sections to maximize conversions.
- **Performance & SEO**: Built with modern web practices, ensuring rapid page loads and optimized metadata indexing.
- **Bilingual DOM System**: Instant layout translations (EN/PT) with full responsiveness across mobile, tablet, and desktop viewports.

### 🛠️ Technologies
- **Frontend**: HTML5, Modern CSS (Flexbox, Grid), Vanilla JavaScript.
- **Integration**: Webhooks / Fetch API for Google Sheets or automated spreadsheet scripts.

### 🚀 Getting Started

#### Setup
1. Clone or copy the folder:
   ```bash
   cd Spartan
   ```
2. Serve the static site locally:
   ```bash
   npx http-server -p 8080
   ```
3. Open `http://localhost:8080` in your web browser.

## 🇧🇷 Versão em Português

O Spartan é uma landing page de alta conversão e site institucional integrado a um sistema de lista de espera sazonal. Desenvolvido para capturar leads qualificados em janelas específicas de lançamento, ele automatiza a coleta e envio de dados diretamente para planilhas de gerenciamento comercial.

### ✨ Funcionalidades
- **Lista de Espera Sazonal**: Formulário interativo de inscrição que abre e fecha dinamicamente dependendo da época da campanha.
- **Integração com Planilhas**: Dispara os dados capturados (nome, e-mail, contato) em tempo real para planilhas remotas (via Google Sheets API, Make, Zapier ou Webhooks).
- **Geração de Leads Eficiente**: Estrutura focada em conversão, com seções limpas, depoimentos e chamadas para ação claras.
- **Performance e SEO**: Otimizado para carregamento instantâneo no mobile e estruturado semanticamente para rankeamento orgânico.
- **Bilinguismo e Responsividade**: Tradução nativa instantânea (PT/EN) e adaptação fluida para qualquer tamanho de tela.

### 🛠️ Tecnologias
- **Frontend**: HTML5, CSS3 moderno, JavaScript Vanilla.
- **Integração**: Fetch API com webhooks de envio para planilhas automatizadas.

### 🚀 Como Executar

#### Inicialização
1. Acesse a pasta do projeto:
   ```bash
   cd Spartan
   ```
2. Inicie o servidor local:
   ```bash
   npx http-server -p 8080
   ```
3. Acesse `http://localhost:8080` no navegador.
